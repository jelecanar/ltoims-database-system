# LTO Information Management System (LTOIMS)

LTOIMS is a database management system designed to manage driver records, vehicles, registrations, traffic violations, appointments, and reports.

## Features
- Driver Management
- Vehicle Information Tracking
- Traffic Violation Monitoring
- Vehicle Registration
- Appointment Scheduling
- Reports Generation

## Technologies Used
- SQL
- MariaDB
- GitHub

## Database Tables
- Driver
- Vehicle
- Traffic_Violation
- Vehicle_Registration
